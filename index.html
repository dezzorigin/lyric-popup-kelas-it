Satu script Python, satu lagu, lima belas kotak lirik yang melayang sendiri di layar. main.py memutar lagu.mp3 dari detik 3:20 dan menelurkan satu kotak lirik tanpa title bar untuk tiap baris climax Olivia Rodrigo — “the cure” — lengkap dengan efek ketik dan pantulan ala screensaver DVD. Halaman ini etalasenya: pemutar di bawah memakai lagu.mp3 dan jadwal yang sama persis.

    Jalanin di desktop

    Pemutar web di atas cuma cermin. Yang asli: python main.py di laptop, kotak liriknya betulan jadi jendela yang melayang di atas semua aplikasi.

    1. Siapkan lagu

      Taruh MP3 yang kamu punya di folder repo dengan nama lagu.mp3 (sudah ada satu di repo ini).

    2. Pasang suara (sekali saja)

      pip install pygame — tanpa ini lirik tetap jalan, cuma tanpa musik.

    3. Jalankan

      python main.py — ESC menutup semua, Spasi cek detik musik buat kalibrasi. Kalau lirik kecepatan, tambah SYNC_ADJUST; kalau kelambatan, kurangi.

    git clone https://github.com/dezzorigin/lyric-popup-kelas-it.git && cd lyric-popup-kelas-it && pip install -r requirements.txt && python main.py

    Butuh Python 3.10+ dan tkinter (bawaan di kebanyakan instalasi Python desktop). Di server tanpa layar / headless, script tidak bisa membuka jendela — itu batas yang jujur, bukan bug: verifikasi otomatis di CI hanya py_compile + uji jadwal lirik tanpa GUI. Lihat docs/TESTING.md.
